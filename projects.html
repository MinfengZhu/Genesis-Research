2025 — Ongoing
Multimodal Prover

GenesisGeo

A Multimodal Synthetic Dataset & Prover for Olympiad Geometry Solving

Most geometry provers only reason with symbols. They ignore visual cues like symmetry and shape, the cues humans use to find the right construction. GenesisGeo uses both. GenesisGeo-1M is a dataset of 1 million problems. Each one pairs a diagram with a proof a computer can check. GenesisGeo-2B is a vision-language model trained on this dataset. It reads diagrams and text together. The model proposes a construction. A fast symbolic engine checks it. This loop repeats until the proof is done.

Gold-Medal Performance

GenesisGeo-2B scores like a top Olympiad competitor. It even found a new, shorter solution to IMO 2008 Problem 6.

Current Progress

GenesisGeo-2B has reached gold-medal-level performance. It solves 29 of 30 problems on IMO-30, and 278 of 409 on HAGeo-409. The dataset pipeline and training method are stable and easy to repeat. We are now working on harder problems, the ones that need ten or more extra construction steps. These are still out of reach.

2025 — Ongoing
Self-Improving Solver

GeoDiscovery

Discovering Geometric Knowledge from Machine-Generated Proofs

Even the best geometry solvers use a fixed set of rules. Once a problem is solved, the reasoning inside the proof gets thrown away. GeoDiscovery keeps it. The system has four steps. First, proof generation solves new problems and keeps the verified proofs. Second, rule extraction pulls new reasoning patterns out of these proofs. Third, counterexample-guided refinement checks each new rule against edge cases and adds guard conditions where needed. Fourth, rule reduction merges and prunes rules to keep the set small. The new rules go back into the solver. The next round starts stronger.

🔍

Proof Graph Mining

Cleans up each proof trace. It removes steps the solver already knows, and keeps only the new reasoning.

🛡️

Counterexample-Guided Refinement

Searches for edge cases that break a new rule. Then it adds the missing condition that fixes the rule.

♻️

Recursive Self-Improvement

Three rounds beat one big round, using the same budget. New rules unlock new proofs. New proofs unlock more rules.

Current Progress

We have run three rounds of rule discovery, using a shared budget of 750,000 proofs. The last round alone added 291 new rules. Solve rates went up across the board: 157 to 203 on JGEX, 9 to 12 on IMO-30, and 54 to 72 on HAGeo. On some benchmarks, our rules now match hand-written human rules. Current work groups these rules into higher-level ideas, and improves how well they work on human-written problems.
